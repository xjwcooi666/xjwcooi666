## 文档总览

本仓库当前尚未包含可对外使用的公共 API、函数或组件。文档结构与模板已经搭建，后续在提交或更新代码时，请同步补充相应章节的内容与示例。

### 文档目录
- 入门指南: docs/getting-started.md
- API 文档总览: docs/api/README.md
- 公共函数: docs/api/functions.md
- 公共组件: docs/api/components.md
- 模块与命名空间: docs/api/modules.md
- 使用示例: docs/examples/README.md
- 文档撰写规范: docs/writing-guide.md

### 如何更新文档
- 在新增或修改公共 API、函数、组件时，更新对应的文档页面。
- 在代码中添加结构化注释（如 JSDoc、Python docstring 等），并在文档中同步示例与使用说明。
- 如果有破坏性变更，请在文档中显著标注，并提供迁移指南。
